# 블로그에 오신 것을 환영합니다!

Next.js와 MDX를 활용해 기술 블로그를 만들었습니다.

## 주요 기능

이 블로그는 다음과 같은 기능을 제공합니다:

- **MDX 지원**: Markdown에 React 컴포넌트를 포함할 수 있습니다
- **태그 시스템**: 각 포스트에 태그를 추가할 수 있습니다
- **반응형 디자인**: 모든 디바이스에서 최적화된 경험을 제공합니다
- **다크모드**: 시스템 설정에 따라 자동으로 다크모드를 지원합니다

## 기술 스택

```javascript
const techStack = {
  framework: 'Next.js 15',
  styling: 'Tailwind CSS',
  content: 'MDX',
  language: 'TypeScript'
}
```

## 앞으로의 계획

앞으로 이 블로그에서는 다음과 같은 주제들을 다룰 예정입니다:

1. 웹 개발 관련 기술
2. 알고리즘 및 자료구조
3. 프로젝트 경험 공유
4. 개발 팁과 트릭
