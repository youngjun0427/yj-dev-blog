# TypeScript 유용한 팁 5가지

TypeScript를 사용하면서 알아두면 좋은 실용적인 팁들을 소개합니다.

## 1. Utility Types 활용하기

TypeScript는 다양한 내장 유틸리티 타입을 제공합니다.

```typescript
interface User {
  id: number
  name: string
  email: string
  age: number
}

// Partial: 모든 속성을 선택적으로
type PartialUser = Partial<User>

// Pick: 특정 속성만 선택
type UserPreview = Pick<User, 'id' | 'name'>

// Omit: 특정 속성 제외
type UserWithoutEmail = Omit<User, 'email'>

// Readonly: 모든 속성을 읽기 전용으로
type ReadonlyUser = Readonly<User>
```

## 2. Type Guards 사용하기

런타임에 타입을 체크하는 방법입니다.

```typescript
function isString(value: unknown): value is string {
  return typeof value === 'string'
}

function processValue(value: string | number) {
  if (isString(value)) {
    // 여기서 value는 string 타입
    console.log(value.toUpperCase())
  } else {
    // 여기서 value는 number 타입
    console.log(value.toFixed(2))
  }
}
```

## 3. const assertions

타입을 더 구체적으로 추론하게 합니다.

```typescript
// 일반적인 경우
const colors = ['red', 'green', 'blue']
// type: string[]

// const assertion 사용
const colors = ['red', 'green', 'blue'] as const
// type: readonly ["red", "green", "blue"]
```

## 4. Template Literal Types

문자열 타입을 조합할 수 있습니다.

```typescript
type Color = 'red' | 'blue' | 'green'
type Brightness = 'light' | 'dark'

type ColorVariant = `${Brightness}-${Color}`
// "light-red" | "light-blue" | "light-green" |
// "dark-red" | "dark-blue" | "dark-green"
```

## 5. satisfies 연산자

타입 체크를 하면서도 정확한 타입 추론을 유지합니다.

```typescript
type Config = {
  [key: string]: string | number
}

const config = {
  apiUrl: 'https://api.example.com',
  timeout: 5000,
  retries: 3
} satisfies Config

// config.apiUrl은 string 타입으로 추론됨
// config.timeout은 number 타입으로 추론됨
```
